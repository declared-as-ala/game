# Carré néon fermé — collisions entre billes

## Modifications

- le carré est entièrement fermé, sans ouverture ;
- les billes rebondissent sur les quatre parois ;
- lorsqu'une paire de billes entre en contact, une nouvelle bille apparaît ;
- une paire ne crée qu'une seule bille tant qu'elle reste en contact ;
- texte en haut : **Want to see ur name in the next video? 👀** ;
- aucun bouton visible ;
- enregistrement vertical 1080 × 1920 à 60 FPS.

## Enregistrement

- appuie sur **V** pour commencer l'enregistrement ;
- appuie une seconde fois sur **V** pour arrêter et sauvegarder ;
- tu peux appuyer sur V dans la fenêtre principale ou dans la fenêtre d'enregistrement ;
- les vidéos sont enregistrées dans le dossier `recordings` du projet.


## Correction v9
- Un contact entre une même paire de billes ne crée qu’une seule nouvelle bille.
- Le contact ne peut être réarmé qu’après une vraie séparation.
- Ajout du texte « Every contact = a new ball ⚡ » en haut.
